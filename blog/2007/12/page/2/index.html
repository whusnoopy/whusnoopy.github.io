被拒, 还是有点小难过的

2007年12月15日

今天下午, 突然发现邮箱里的有聊天信息, hr, 问我为什么手机关机, 一看就知道应该是和 offer 有关的, 告诉她我手机是武汉号没法漫游, 然后她说是有关面试的一些事情, 立马发了一个 reject? 过去, 然后那边果然是确认的这个消息. ok, 就这样吧, 也是在意料之中吧, 并且, 这个 reject 还来的迟了太多, 并且, 居然是在 EMG 卡了那么久最后才被拒掉. 其实我猜是因为 GPA 的问题, 跟 tlp 说被拒的时候他都很难以置信, 说都到了 EMG 怎么可能会被拒掉, 等我告诉他我 GPA 后才很遗憾的无奈苦笑 :( 后来想跟 hr 确认一下这个原因, 得到的答复是 “项目经验不够”. 想了一下就觉得应该是安慰的话吧, 一个本科生怎样都可以被这个帽子扣死, hr 也有 hr 的难处, 我们也还是要体谅的 :)
其实, 本来也没有抱太大希望的, 但是, 现在还是很有点小难过, 毕竟等了很久同一批面试的人要么被拒要么拿到 offer 后我还是一点消息都没, tlp 告诉我说都已经到 EMG 了, 然后还是很 YY 了一下, 又重新来了兴趣, 但是, 现实还是现实, 还是要面对的, sigh.
回去武汉继续下一个两年, 其实, 这似乎才是我一开始设计好了的未来. sigh, 突然又觉得, 我为什么要把那么遥远的未来都规划的那么好? 人生为什么要这么有规律, 一点意思都没, 一路过来, 都是已经算计好过的, 我只是把很多图纸变成现实, 把很多设计文档转变成最终代码, 其实, 什么都没变. 是的, 其实什么都没变, 一直都是, 所有的事情都是在按照我希望的方向前进, 偶尔 YY 的狗屎运也都没走上, 不知道两三年后, 自己是否又会感慨, 现在过的其实不过是两三年前想了无数遍的生活, 做想过的事情, 想的, 说不定也还是想过的念头.

嗯. 未来一小段时间的计划, 尽可能在代码意外有更多的生活, 做饭, 画画, 轮滑, 骑车远游, 这些是可以做到的, 并且相信也是一定能做到的, 至于学一门乐器, 比如吉他, 则应该是 plus 的内容了, 并且, 应该要保证自己对明年的两个 Dev 方面的许诺.

晴天娃娃

2007年12月8日

那天装好 Linux, 然后就想看看在 BIOS 里开了 Modem 后声卡好没, 拉电影看了下, 然后就听到 <不能说的秘密> 里橄榄球赛那段的音乐, 很好听, 去找到名字, 晴天娃娃, 感觉好像很熟悉, down 歌, 然后去查晴天娃娃是什么. 后来找到这个很可爱的东西, 就是一个小玩偶, 大家还记得一休里那个吊在树上的小玩偶么? 我感觉就是一块白手帕包住一个乒乓球, 画上脸谱, 然后用绳子系住挂窗口了, 很可爱 :) 最近开始更愉快的生活, 想起前几个星期一直在地铁里看的连续剧, 晴天日记, 后来也特意去网络上去看了看, 好像我坐地铁还是把前面三集看全了, 广告或者其他成分抛开不谈, 至少宣传摘录的部分都是很开心很阳光的, 地铁其实也是个很有意思的地方. er. 我想说什么呢? 晴天, 嗯, 晴天里人的心情还是会好很多的, 特别是有开心的音乐一起.
歌词很有意思, 特别是副歌那段: “我讨厌下雨天亲爱的你快出现, 不然我就告诉妈咪你偷牵我的手”, 太可爱了 :)

什么时候自己去弄个球做个晴天娃娃挂桌子旁边吧, 现在那个 McD 的熊也都没怎么注意他了 :) 收到魔方, 手感差好多啊… 原来那个真的很紧很紧… Rubik’s 的特色么?

一个周末都花在了 Ubuntu 7.10 上

2007年12月3日

其实也用不了这么久的, 其实也还是做了点事的. 记录一下过程, 中间确实很郁闷

下载 alternate 版的 7.10 iso 文件, 一切正常, 只是无线貌似被限速了, 100k 不到的速度爬了两个小时终于下来了, 然后就很开心的找网络上说的不刻盘直接用 grub for dos 直接装的方法. 这里犯了一个也谈不上错误的错误…(什么逻辑), 网络上一般都是很开心的指导说去下载 vmlinuz 和 initrd.gz, 而我看一般提供的那个下载点太慢, 同时看到另外某个老版本的指导上说是可以直接从 iso 文件里弄出来的, 试了果然有, 然后很 happy 的解压到 C 盘根目录, 开始装. 结果每次都是说无法加载光驱(其实是虚拟光驱上的 iso 文件), 重启了无数次, 把 7.10 那个 iso 放在各种教程上写的地方试过都无效后终于开始怀疑那两个文件了, 搜半天找到一个还不算慢的地方弄下来, 一对比, 果然 initrd.gz 那个文件不一致, ft, Ubuntu 的一群人渣, alternate 的 iso 里文件都不行. 后面的就没什么特别的啦, 一路安下去, 然后找源, sudo apt-get update, sudo apt-get upgrade, 晚上的时候看看还要两个小时, 然后就很开心的过去打了个电话回家, 跟老妈聊了半天, 回来一看预计结束时间更久了, 汗, 看来还是应该去选台湾的源而不是 lupaworld 的那个. 看看时间不早, 索性回去吧, 周六就这样结束了. 周日过来后就开始看 compiz 的效果, 死活打不开, 继续搜, 搜了无数用 ATI 显卡以及 T60 机器的问题出来, 挨个试, 后来也不知道怎么好的… 因为做过的操作太多了, 据说是只要装好驱动和 xglserver 就行了的, 我的貌似是驱动启动有点问题所以我 disable 又 enable 再重启后就好了. 接着就是在整 SCIM 的输入法和 emerald 的主题, 主题倒是很快弄好了, 还顺带优化了一下字体, 但是那个该死的 SCIM 怎么也不好, 崩溃啊, 几乎所有能试的方法都试过了, 最后在某个很诡异的地方看到一个很诡异的解答, 说在语言支持里把某个框去掉, Apply, 再选上, 再 Apply, 然后重启 X 就好了, 对着做后果然好了… ft. 这都什么系统什么毛病啊. 期间还有一个很诡异的 vim 的毛病, 居然不能写 syntax on 进 .vimrc, 并且 help syntax 等都不能用, 后来想是否需要重装一下, 直接 vim 看是 7.1, 但是 help 后即使 6.4, 直接崩溃, 并且在 Synapitic 里看也都装了, 不管了, 重装了一大堆跟 vim 有关的东西后终于一切正常了(继续感慨这都什么破玩意儿啊), 把自己喜欢的配置写好, 真爽.

目前系统运行貌似都还好, compiz 能用(就是为了这个才装的 7.10), SCIM 能用, 其他设置也都还好, 主题不难看, 就是字体还有改进空间(某些应用程序下中文显示不是特别好看或者很多显示不出来?).
