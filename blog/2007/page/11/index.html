其实, 哪有那么多不开心

2007年2月2日

其实, 生活本来就是很单纯的, 应该很快乐, 哪有那么多不开心, 哪有那么多要想的乱七八糟的事情.

你说, 我们要让生活更美好, 但是, 美好的生活就应该是不开心的么? 你说, 以后就会快乐的, 但是, 现在都快乐不起来, 以后我们还会记得如何去寻找快乐么? 是不是又一次一次的把自己陷入迷茫, 沮丧.

生活应该是贪心一般的简单, 而不是 DP 一样的计较, 更不想是计算几何的麻烦和精度处理. 搜索的时候, A* 差不多就好了, 没必要为了去找一个最好的限定函数而错过那么多机会, 错过那么多意外的美丽. 如果一切都是计划好了的, 那跟跑一个预先知道结果的程序有什么区别, 不过是一些 0110 的转换而已.

07 年, 我要做东西, 找实习, 攒钱, 买本子, 不想考研, 想去工作.

内网服务器终于弄好了

2007年1月30日

跟董老师说让把后面另两台机器的还原卡给去了, 然后都装上了 RHEL AS4, 按计划, 一台给内网做服务器, 提供 http, ftp, 打印 等服务, 同时准备留给未来做 PC2 的服务器, 另一台做 OJ 的测试服务器.

今天弄内网服务器弄了半天终于搞定, 麻烦死了, 最后发现问题都在那个该死的防火墙上.

一开始配打印机, 一开始没插电, 系统没找到, 等找到后设置成共享, 其他机器却不能访问 查了一下 Google/Baidu, 启动 samba 服务后还是不能访问, 以为是 samba 配置的问题, 查询了无数的东西后突然想是不是防火墙有问题, 关闭后就 OK 了, 无语. 按照 linuxsir 上的介绍, netstat 查看了一下 smb 的端口, 然后在防火墙中打开这两个端口, 搞定.

然后启动 ftp, 跟在外面那个服务器一样的启动 vsftpd, 写配置, 发现又不能访问, 怒… 通过查看 FlashFXP 的记录发现最后调用了一个很奇怪的端口, 65xxx, 想了一下估计又是被服务器拦了, 一怒之下索性把防火墙关了, 懒得去管端口设置了.

最后启动 http 服务, 这个很容易, 乱搞就搞定了, 不过默认好像是不启动 httpd 的, 又要自己开了一次. 一切搞定 :P

那台准备用来做 OJ 测试服务器的机器还没开始配, 看看明天上午有空就把 OJ 在上面跑起来.

继续 TopCoder

2007年1月26日

回头看了看, 把分类 “集训感受” 改成了 “竞赛人生”, 是啊, 其实一直都生活在各种竞赛中, 与其消极规避, 倒不如正面对待.

今天上午 TopCoder SRM 336, 没钱的比赛, 本来也不想做的, 后来想想反正无聊, 继续吧. 不过第一次 Div I 的比赛就做的奇挫无比… 250p 卡在了输入上, 一个小细节很久后才调整过来, 500p 想了很久实现, 不过做出来的分数也还好, 900p 没空做了, 开了发现是个非常非常麻烦的计算几何, 求一点对一个立方体在某平面上的投影面积. omg. 没被人 cha 掉, 也没去 cha 人, 没什么好 cha 的. 可惜在 System Test 里两个题都 Failed 了, 看了看一个是段异常, 还是不知道自己哪里弄错了, 看了看数据貌似也只是有点大而已, 其他倒也没什么, 另一个估计算法实现还是有问题, 在一个很特殊的情况下错了.

从 13xx 分掉到了 12xx 分, 太失败了, 下次做好点, 不然又回到了 Div II, 虽然可以拿钱, 不过 Algo 的钱也最多算零花吧, 玩玩还可以.
