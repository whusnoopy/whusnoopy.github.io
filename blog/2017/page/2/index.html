莫莫十五个月

2017年7月9日

家里人都觉得莫莫长得小只，一岁后的例行体检本来是十八个月，但还是十五个月自行去加了一次

带鞋 9.2kg 76.5cm，比过年时重了不到半斤，考虑冬天衣服的问题，也长了不到一斤，身高是长了一点，显得更瘦了

但不管怎么说还是在标准范围内，别的娃也没像莫莫这样精力旺盛动个不停，消耗太多，也没法长肉

给抽血验了下各种微量元素，除了有点缺钙，其他各种微量元素和维生素 D 也都好的，每天配方奶吃三顿共快 600 毫升，按说也不缺，维 D 够应该也不影响吸收，但怎么就是缺钙呢

牙还是八颗，几颗槽牙已经鼓包很久了，就是没冒出来

成天疯跑，在家总还是磕到头或摔跤，脑袋上总是有包，大哭一阵哄一下就好，各种摔也是小朋友成长的必经过程吧，还好最近已经很少了，还是长记性了的

想说话，但大部分时间还是说的谁也不明白的小朋友语，听到最多的是 不要，以及不要的各种变形，比如 不吃，要不得，让人哭笑不得

天天爸爸妈妈大大挂在嘴边，问他谁在哪里都能分清，包括出去玩一堆小朋友谁是谁的家长也能分清，但是喊的时候就乱来，可能也是大部分时间他就是随便叫着玩

大这个字经常是发出 大气 的音，小区里的小朋友都管他叫莫大哥了，一直大大大也并不是要打人或怎样

去过一次动物园，看到过大象，后面在家里说大大大很多时候其实是在说大象，因为说的同时会指着某本书上给你看大象，问他大象在哪里，除了找书，还会指着动物园的方向表示那边有。最近天太热，暂时还没继续带去动物园玩

爷爷放暑假了过来一起带莫莫，但是快一年没见了总还是不够亲，在家更多黏奶奶和爸爸，让爷爷好不伤心

爷爷奶奶都来杭州了表伯母就回家陪自己的娃了，本来担心换人带会不会还有不适应的，发现是我们想多了，小朋友的适应能力还是挺好的

小区门口新开了个婴幼儿游泳馆，想着去年在家用小浴缸都游的那么开心，带他去围观时也超爱玩水，就办了张季卡，不过去游的时候并没有去年那么开心了，还是要适应一下么？

在家洗澡也不乐意坐着洗，非得站着，洗到后面总要哭闹一下，去游泳馆游完出来游泳馆阿姨帮洗的时候，奶奶和其他人都在旁边的，也还是免不了要哭哭一下，明明我们在小区里都是超大胆的宝宝，怎么去到那边要被人说害羞胆小了呢

在餐椅上吃了一个多月，天气热的不行后又不太干了，可能还是坐着出汗热，开空调了也压不住这把旺旺的小火苗

妈妈给买了个新的小车车，主要还是看之前的童车坐着太热，现在坐上去推着走，以后可以当自己踩的三轮车用，有新车了贼开心，到的那天爷爷还没装好就要上去试

不过妈妈之前买的滑板车还是没有那么愿意玩，虽然出去时总去折腾别的小朋友的。安的座位坐上去没两秒就要下来，这么小也还不会一个脚踩上面另一个脚蹬着走

在家玩时总喜欢把东西塞到沙发底下，可能看之前有不小心塞进去后我们给他弄出来的样子很好玩，后面自己塞了东西后也学我们弄爬行垫边上的包边当棍子去扫出来，可惜小朋友还是没完全学会我们是怎么弄的，更多的时候都是在把可以用手拨出来的给捅到墙角去了

618 时尝试买了几包拉拉裤，白天穿是方便和舒服不少，特别是小肚肚前面没那么厚的卡住，蹲下去容易点。但是拉拉裤存不住那么多尿，要稍微换勤快点，不过天气热了本来也要换勤一点免得捂住。晚上还是用传统的尿不湿，睡觉放心点

关于奶粉，之前屯的德爱 1+ 段还有最后两盒，在买新奶粉前对比了下各种版本的微量元素等，感觉德爱的各种微量元素和维生素加的有点多，可能是按每天只吃一两顿来配比的，莫莫现在每天中午和晚上睡觉前吃一次，凌晨快起来时还要吃一次，怕超标中毒，最后买的国行爱他美替换

莫莫十四个月

2017年6月14日

期待已久的第九颗牙并没有出来，耐心等，也许一下子又是好几颗同时出

夏天到，穿的少，动的多，体重跟过年时还一样

吃的花样足够，奶，辅食，水果，零食，样样不差，量也不少，架不住太好动不长肉

走路已经不用扶，连在旁边护着都不用，护他还要把大人手打开

会走后很快也会跑了，现在大部分时间都在跑，而不是稳当当慢慢走

力气越来越大，可以自己双手抱起六包装的湿巾站起来还走两步

单手拎一罐坚果还能把手举平，这是练习狙击手举枪手不抖么

随便踩点啥就能爬上沙发，围栏也往上踩着爬，根本关不住

干脆把围栏撤了，把家里茶几什么的也挪下位，空间都腾出来让他疯跑

还好奶奶回来了，两个人轮着看还好，现在已经没法安心让他单独呆着了

呆不住，在同一个地方最多待三秒，立马要换地方，小朋友每天都有摔跤或磕碰，看脸上挂花或额头肿包，牙齿出血或咬破嘴皮，虽说娃都是摔大的，但看着还是心疼不已

本来想把一直不坐的餐椅给收起来，收前不死心再让他坐上面吃试试，现在反倒可以坐上面吃完了，知道闹没有用，不饿我们也不强迫喂，不像原来要追着搞半天，大家都舒服

各种水果都给他尝尝，最喜欢的还是火龙果，还得是红心的，知道白心的要便宜一半看不上么

樱桃杨梅什么的看着想吃，真喂他又嫌酸，倒是学会喂爸爸妈妈，还能帮着把梗扔垃圾桶去

看他会各种帮忙，会扔垃圾会拿纸擦地，虽然多半还只是学样，但每次都看着好幸福好感动

懂很多事，想要什么会自己过去够，够不着或搞不定的会抓你手去帮他，要出去玩了会自己找门卡，还能分清哪个是自家门卡哪个是单元门禁卡，并且不忘让你带上各种东西

性格善良，出去玩看别的小朋友互相抢东西抢哭了，还会把自己的玩具拿去给人玩安慰别人

不懂事也不知轻重的情况好多了，不在外面当熊孩子欺负别人，胆大心细，霸气外露，别的小朋友家长开玩笑说要叫他莫大哥

跟爸爸一样爱出汗，睡觉也怕热，杭州快到梅雨季节闷热潮湿，晚上得开空调除湿才睡得安稳，白天汗湿了就换衣服，一天换好多套，还好妈妈买的够多

有点粘爸爸，下班回家都缠着爸爸玩，跟爸爸抱抱亲亲也超配合，妈妈各种嫉妒

搂着他的时候就总觉得，小朋友健康快乐，心地善良，好奇对待这个世界，也被世界温柔对待，莫大幸福

莫莫十三个半月

2017年5月23日

1+ 的奶粉吃到第二罐，发现第一罐似乎是不太对，太湿了，用勺舀感觉也怪怪的

而且吃第一罐 1+ 时新勺被莫莫抢走玩，我们还拿的老勺子在量，实际似乎量多了，害了莫莫好久

还好这段时间吃喝拉撒都还正常，玩玩闹闹也挺开心，希望不要留下什么不好的隐患

在户外也可以走的挺好了，只是大人还不敢完全放手，担心他跑快了摔跤，或突然一屁股坐不合适的地上

在小区一块比较平的草坪上，放手给他自己走，摔了也没关系，爬起来继续就好，就这样走稳的

在同龄的小朋友之间算走的早的，其他小朋友家长都学习经验，一窝蜂跑草坪上去学习锻炼，别把草给踩死了

会走了后反倒各种不好好走，总是要跑，真的是「走都不会就想跑」啊

出去玩还是各种霸道，被爷爷看到视频后批评了，很多时候只是带孩子的之间觉得好玩，并没故意教坏

不过脾气是有些坏，也确实要注意下，别养成小霸王一只

胆子挺大，去捉别人带出来玩的鱼或泥鳅都不带眨眼的

也还算有同理心，如果真的抢别人东西把人家弄的要哭了，会主动还回去，表示道歉安慰

不过有时候也胆大的过头了，比如从沙发上下来，就直接头朝下，教了几次会转个方向，让脚先下来

有人在的时候还是会才转到一半就横着往下掉，赌爸爸在旁边看着会捞住的是吧

有一些必要的害怕还是要有的，对该恐惧的事情要保持敬畏，比如高处、深水、电

出去玩都贼精贼精的，经过包子铺，会嗯嗯啊啊的赶人去买包子给他吃

天气热了出汗出的一塌糊涂，热了睡的也不踏实，随便盖一点都容易热的乱滚

衣服穿少后发现手背早晒黑了，手臂和身上大部分地方细皮嫩肉，很是白嫩，差异好明显

有几天不怎么流口水，看岔了还以为长了新牙出来，后面发现并没有，估计当天看到的是饭粒或奶渣

从过年到现在就没长过，还是十八斤，不过现在衣服穿的少了，基本可以等价净重

虽然小区其他人看到说长肉了，大家抱着也觉得似乎沉了点，但上秤就是十八斤，好无奈，急也没用

经常调侃莫莫说你吃的也不少啊，是不是都被天天走不停给消耗掉了啊，出去玩基本就没有歇的时候

家里人都认识，可以准确的在照片上指出谁是谁，能比较准确的发爸爸妈妈和奶奶的音，但还是会乱喊

自己各种书上的东西也认识挺多，问他什么在哪里，可以翻来指给你看，但是不能一直问，问多了就不配合

基本的颜色应该也是认识的，让拿不同颜色的球也可以准确拿过来，还是问多了就乱来，不想理你

学会飞吻，虽然不甚标准，每天早上爸爸开门去上班时，跟爸爸飞一个，幸福死了

跟他玩时说亲爸爸一个，心情好的时候就会跑来么一个，留一脸的口水，心情不好就装没听见

偶尔会很粘人，伸手要抱，抱起来后会立马缩脚，生怕你把他又放下去了

坐车还是挺容易出汗，出汗后就焦躁不安，如果没哄住，嚎嚎大哭出更多汗，恶性循环

还是「安全座椅不扣那么紧」「开窗或开空调保持车内温度」「陪玩哄吃分散注意力」多管齐下才行

一如既往喜欢年轻漂亮的姑娘，年轻阿姨来抱就毫不拒绝，其他生人就不行

在小区里也喜欢追着比自己大的小姑娘跑，有放学回家穿裙子的小姐姐，就想跟着人家走

莫莫十三个月

2017年5月3日

小朋友长大真的是好快的事情，半个月前还只能扶着围栏站和走，刷刷刷就会独站独走了

已经可以站原地不动好一会，走的过程中偶尔也停下来站一下

已经可以轻松围着围栏转圈，从这头走到那头更是小意思

刚会独走时双手会举起来掌握平衡，没两天走稳了胆大就两个手放下来走，到沙发或围栏边打算停下时才伸手扶一下

对自己能走了超级高兴，高兴时自己在围栏里大喊大叫走上半个小时

这几天都开始眯着眼睛走了，是对自己走的更有自信？简直是胆大妄为啊

会拍手，要跳舞，有音乐时摇摇晃晃跟醉拳一样，或者跳舞手撑地脚反抬，是学的街舞么

吃水果时要自己吃，抱着削皮后的香梨或苹果自己啃

不过还是吃不了那么多，前面还能咬碎咽下去，后面就咬着玩，咬下来在嘴里含一下就吐掉，吸点果汁

自己学会分享吃的给别人，吃馒头或水果时，学大人模样，掐一点在手指上喂别人

自己拿着馒头吃的可香

会想要跟别人交换玩具，想玩别人的东西知道拿自己东西去跟人换

有时候没带玩具出去，会把自己湿巾甚至衣服拿去跟人换，可逗

记忆力好，看到别人童车里有自己想吃的，一大堆车里总能找到自己想要的，把停一堆的童车打乱还能找到

奶奶因为办退休的事回去一段时间，要辛苦表伯母在家带了

奶奶回去前一起出去了一天，完成在外面喝奶睡觉的尝试

中午莫在大人吃饭前自己吃奶睡了，大人吃饭期间放童车里睡了四十来分钟，跟平时出去玩的情况差不多

可能是在超市里太兴奋了，玩的出汗加商场里开空调，这几天感冒反复，整个人都蔫蔫的，一直粘人要抱

小朋友生病不舒服真的是太折腾了，自己还不会说话表达，只能各种闹，大人也各种操劳

本来可以好好坐餐椅吃饭的了，又变成要一人哄一人喂，后面还要出来到围栏里边玩边吃

表伯母为了省掉哄他的人，干脆直接在围栏里追着喂了，结果这货变本加厉，在围栏里还要有人陪玩再追着喂

比以前更爱吃水果了，各种水果自己拿着试探着咬一咬

草莓还没咬就学爸爸酸到的样子眯眯眼，苹果什么的咬一块嘴里嚼嚼又吐出来渣，估计只是磨牙顺便含点果汁出来

总盯着别人手里的吃的，觉得要好吃些去抢，自己手里的不想吃或想跟别人分享时会主动往别人嘴里塞

小手越来越灵活，之前吃手指饼干最后一点捏手里的不知道怎么送进嘴里，现在倒下手就可以一点不剩

咬人咬的越来越厉害，表伯母帮穿衣服或换尿不湿时抱住手臂就是一口，还带撕咬的，被咬的乌青乌青

爸爸陪玩时已经各种小心躲开，还是免不了被他偶尔迅雷不及掩耳之势上来就一口，肚皮上隔着衣服都被咬的破皮

妈妈也没有幸免于难，手臂隔着衣服咬的里面淤青就算了，以为他凑过来亲亲的结果脸上也被咬出牙印

爸爸换大车后对坐车就没啥排斥的了，一般去的路上一路东瞧西看，回来时随便摇下就睡着了，下车都不会醒

不排斥坐车后周末就可以带着出去玩下，印象城逛个街或者浙大遛弯，只是出去时间还没特别长，就上午一会

在打算出去玩带更多装备，这样周末出去在外面吃午饭也没关系，中午要吃奶在外面给冲，要睡有推车可以放平睡

果然还是之前的小 Polo 太小了，估计是感觉压抑，换大车空间大有天窗加上把安全座椅也没扣那么紧就好了

在围栏里玩玩具喜欢把东西从围栏的洞里扔到外面地板上，让大人去捡，然后他再扔，乐此不疲，坏习惯

不知道是天气热了还是别的什么原因，最近两天睡觉特别奇怪，白天都只睡四十分钟，晚上倒是睡的踏实多了

前面有一段时间早上七点出头自己醒或把他温柔的叫醒，这样白天午睡和晚上睡觉都要规律很多，还是早睡早起好

莫莫一岁

2017年4月8日

莫莫一岁啦

体检身高 73.5 体重 9，都是中位线以下正常范围 15% 分位的样子，BMI 倒是刚好中位线上，典型的小小个。头围 48 也是中位线标准，脸上也有肉，看起来都还挺有肉的，这点随他妈妈。天气不热时穿多了看不出来身体小个，天气热了穿少了就彻底暴露。出牙八颗，爱咬人还流口水，口水兜要不停的换。能扶站扶走，有人牵着点也各种迈步往前走，根本不愿意原地站着不动。活泼好动，就没有能停歇的时候，吃的没超多运动量那么大，难怪不长个，力气倒挺大，瘦是瘦有肌肉

至于本地缺失的再怎么导回就再说吧，刚在 Disqus 插件里试了下说 Disqus server return 500，可能回头在 Disqus 里直接导出，然后 WordPress 里直接导入是可行的
