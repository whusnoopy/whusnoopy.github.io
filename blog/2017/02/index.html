莫莫 Week47

2017年2月24日

能扶着沙发或围栏站稳，可以顺着沙发或围栏扶走，超级麻溜的趴倒翻身坐起来和爬来爬去

有人在旁边时会特别大胆，本来扶着站的撒开扶的手想走，知道你看着不会让他摔

趴在围栏上够外面茶几或别的东西够不着时，会踮脚去够，有时候想看别人在干嘛也会踮脚

站着的时候超级像穿靴子的猫，大眼萌娃一脸呆萌的专注看你，还有帽子上的耳朵效果加成

高兴了会抓着围栏使劲摇，应该是自己想蹦蹦跳跳来庆祝但是还做不到

学会了更多手势，每天早上爸爸去上班时跟莫莫再见，小手挥的可好了

两颗上门牙快长齐了，中间的缝长拢了挺多，其他的牙还没出来

白天都能玩的很好，就是晚上睡不好，隔一两个小时要醒一回，苦了带睡的表伯母

吃辅食也都能吃完，前面还会吃一半各种闹腾要边玩边吃，最近放餐椅上有闹腾，但可以想办法让他坚持到吃完

各种水果似乎最喜欢的还是甘蔗，因为能咬着玩

煮过的香蕉苹果和梨也都不是很喜欢的样子，草莓会手捏着玩但也没有特别喜欢吃

有一次吃手指饼干时奶奶担心吃太多，从他手里抢过一回，后面就再不主动把手里的吃的给奶奶，没事还提防被抢

出去玩喜欢追别人的球，小区里喜欢熊猫雕塑，爸爸就去买了个一样的球和一样形状的毛绒熊猫回来

喜欢抓妈妈的眼镜，终于把眼镜腿给掰断了，故意提醒妈妈这副眼镜度数不够镜片也磨花该换了么

吃的多了但是拉的也多，还是没太长个，而且经常是吃饭吃一半时拉臭，小坏蛋怎么选的时机都

最近还经常一天拉两回，量也不少，那么个小肚肚怎么就能拉那么多呢，吃的不消化吸收怎么长啊

得过一次幼儿急疹，某天突然莫名发烧，烧了两天然后全身出疹子，再过了两三天就好了

这个似乎也不算生病，很多小朋友就是要有这么一次，出疹子也不痛不痒，就是发烧时难受

不喜欢被捆着，不管是坐推车还是餐椅还是安全座椅，爸爸带着去一趟浙大紫金港一趟超市，回来时都哭一塌糊涂

有一段突然学会了自己故意眼睛闭着假哭，大人做别的没留意他时，会扒着护栏站着眼一闭嘴一张嚎一嗓子

不过真哭和假哭还是区别挺明显的，演技还是不够，被看穿后如果嘲笑他也会生气，用不理你来表示

感觉有时候是故意撒娇发嗲，有多人在的时候就闹腾，如果就一个人看着反倒会乖巧很多

小小的人儿其实什么都懂，就是不会说而已，每天陪他可爱的长大，是为人父母最幸福的事吧

2016 年度盘点（完整版）

2017年2月12日

补全 2016 年度盘点（简略版）

莫莫

2016 最大的变化就是莫莫出生了，生活重心也随之转变，各种照顾吃喝拉撒睡陪玩，各种买买买。因为照顾莫莫的人变的还是有点频繁，老实讲感觉并不是很好，总觉得我们好像还有很多事情并没准备好，这种情况下把莫莫带来这个世界有点不负责任，但是很多事也确实是只有遇到了才能知道有这回事并去解决

关于莫莫的成长细节就不在日常的记录之外再多讨论。整体上除了有一点闹，其他都好。笨狗觉得莫莫并不像部分家属担心的有很多问题，吃饱穿暖心情愉悦就好。比小胖子们瘦，但是也没有超出正常区间。希望莫莫能一直开心自由的成长，我们替他解决物质问题，在心智成长上给予正确的引导，剩下的还是看他自己，不要以大人喜好去强行安排他的人生，他的人生应该他自己去享受

工作和学习

看了下 git 记录，全年合并提交 1141 次，大部分工作还是跟重构相关。这是个跨了一年的坑，最后的结果还算凑合，不过过程中略失控，太漫长

一开始只想把前端一个超大的 css 文件拆成 less，把通用的组件、颜色和尺寸都变量化，这样后续要改都能一次改掉所有的，新增也能按统一规范来新增。拆的过程中发现很多东西并不那么好拆分，有大量的 ID 选择器，也有很多类选择器被用在 js 里，干脆重写

一边用 Less 拆分重写样式表，另一边熊也先把一个超大的 js 拆成若干小文件，至少维护难度低一点。拆 js 过程大家对之前的结构组织都没法忍受，也打算重写，这时候过早为未来考虑，说以后大屏都统一成一套（Web、千牛电脑版、大屏手机直接用浏览器），小屏统一成一套（手机千牛、手机淘宝，手机浏览器），后端接口也要统一成 RESTful 的，那么整个代码结构和逻辑都要大改

先把一些独立的页面先切到了新版，也保证了千牛上的一致性，然后从商品选择器这个大控件下手，开始切部分页面，里面逻辑比预计的复杂太多，过程中也考虑了很多之前的坑和新加的需求，整体进度从这时候开始失控

七月初新进一个设计师，花了比较多时间去沟通我们的产品是怎样的，一些细节都是怎样的考虑，把已经做完的往新设计上靠，要做的事情也往这上面走，八月份这位设计师又走了，很多事情又不知道该怎么推进，还是回到先实现功能再考虑样式适配的路上

十月份把已有功能基本开发完成，开始做各种测试和样式适配，美折里的产品细节远远超过之前自己体验的和预计的，到处都是一些神奇的坑，填坑填的很痛苦。等把功能测试和样式适配完成，并做了一堆浏览器适配后，在 2016 结束前终于全量上线

全年花了很多时间在招聘上，走了很多弯路，还好在年末算是走入一个比较靠谱的轨道。直接带了两个新同学，间接算也还带了一两个人，整体上比预想的要好，年末时 Gardon 加入，感觉子煜已经带上道了，就把想弄前端的他转给了 Gardon

没有花什么时间去成体系的学什么技术方向，更多的是把前端开发的各种技能给点上，同时实践 js 的各种坑

在管理和企业文化方面看了一些书，但是觉得目前还用处不大，该有的总会有的，对付不来的东西似乎一时半会也推不动。不过倒是认识到了一些自己以前没注意的缺点，比如只关注过程觉得自己努力把事情做好了是不够的，结果才重要，没有结果过程做的好意义也不大，当然如果要说过程就是学习经历不要在意结果，那么这个学习经历也是有学习的结果的，比如不要去抠很多细节，该放的要努力放手，把握好关键点，放得出收得回就行。另外就是要更重视沟通的方法和技巧，跟不同的人打交道的确有太多不一样的方法，就算是能直来直去的，技巧好点也会事半功倍

生活和娱乐

2016 年的第一天收房，拿到人生中属于自己的第一套房子。年初花时间弄了宜家的一大堆家具并在春节前坑爹一起装完，后面没多久把窗帘都弄了，五月份补齐了剩下的一些家具，618 前后把冰箱洗衣机两个大家电搞定，夏天把两个定制衣柜搞定，阳台包好，阳台柜弄好，十二月再弄了电视，另外把书房改成卧室，准备好搬家

跟公司出游，莫莫出生前去了一次菲律宾长滩岛，十一前去了一次上海迪士尼，夏天还去漂流了一趟。自己则就是杭州市区过年前后各种陪家长走了一下，并没有点开多少新的地图，倒是宜家去了好几次，不过不是当主题公园在刷，而是正儿八经在买东西

莫莫出生后各种操心和瞎操心，瘦了快十斤，端午节时家里出了些状况喵带着莫莫回老家呆了一个月，笨狗一个人回杭州后身心疲惫了一阵（本想说大病一场，好像也没啥，就是各种憔悴），习惯后就好多了

念叨了一年多换车的计划也没成行，一方面是租在城区停车不便，周末都没开车回去，换车的主要目的是周末带莫莫出去玩，这个就意义不大了，另一方面是好像也没那么强烈紧迫的需求，也没空去看车，搬家后再严肃点考虑这个问题吧

数码和败家

有莫莫了以后就没怎么给自己添置设备和败家。喵的 iPhone 6 因为 16G 存储各种捉襟见肘，等 iPhone 7 一发布就定了一台 128G 的给喵，是个惊喜，推推拖拖后面也还是开心的用起来。老爸说他的红米 2 电信版屏幕出了问题，十一前给换了个红米 Note 3。喵妈妈十一后在这边带娃辛苦，生日时没买别的，也买了个红米 Note 3 替换掉了之前喵淘汰给她的红米 Note 一代，刚好在这边能用上笨狗的电信副卡，回去喵爸换了电信套餐后也一起用电信了

其他的很多小玩意儿都是为莫莫在买。四月份莫莫出生前买了个小米空气净化器，等年底要自己的公司周年礼物时还是要了个小米空气净化器，八月份准备请阿姨带莫莫前弄了个摄像头，方便上班后看看莫莫都在干啥

莫莫的奶粉尿片辅食这些都是例行项目。童车在五月份又买了个伞车但是似乎依然买大了，叠起来还是不够方便。其他大件有了各种教训后开始进入后爸模式，没那么多冲动买的念头。在双十一前后定了两年的巧虎，每个月收点玩具和小册子也还好的

各种大支出基本就是折腾新房，各种买家具买电器定制装修。还有就是各种家属在老家和杭州的往返路费，有莫莫后本来就要来去的频繁些，加上一些状况更多了不少交通支出

Gardon 入职时要台式机，顺带薅了一枚 i5-6400 替换之前置换客服机的 G1820，明显不是一个档次的东西，这样在家开台式机干活也挺爽，配合 Ubuntu@Win10 开发环境也不在话下

还在用随手记记账。例行的收入还是工资奖金和部分理财收入，继续没折腾股票等有风险和需要花时间的事。公司下半年新三板挂牌后分了一次红，似乎离想象的有点远，但仔细算算也就这样，估计还是想的太美好忘了实际情况到底是怎样。因为莫莫出生和搬新家，倒是从两边家里收了一些大额礼金，这也是个奇怪的收入方式。涨了些工资，加上公积金，才不至于说到手的钱都花光光。整体的资产表，加上各种非例行的收入才算是扭成正的外加些盈余。买房还是个超大的坑，而且对未来的略保守，现在回头看也许该把坑挖的更大一点才对

莫莫 Month10

2017年2月4日

本月从妈妈单位旁边租的房子搬到了自己家的房子里，过年期间外公和老外婆一起过来过年，年后外公外婆和老外婆都回去了，奶奶和表伯母来带，表伯母家有姐姐哥哥，都带的很好，做事麻利也有最近带娃的经验

奶粉还是考拉买的德国爱他美二段，消耗速度比之前慢一点，还有两罐，吃完就换三段了。辅食量上去了奶就少一点，一天一般吃四次或五次，中午睡觉前一次，下午一次，晚上睡觉前一次，半夜或清晨醒来吃一次或两次，一次吃 170 毫升居多（150 的水冲 5 勺奶粉），有时候能吃 200，但担心会撑，吃的密或不怎么饿时就吃 120 左右了

辅食的米粉这段时间一直吃的考拉买的嘉宝混合谷物，各种成品辅食似乎没再吃了，都是自己弄的。猪肉、猪肝、鸡肉、好几种鱼混着提供肉类来源，鸡蛋黄从大半个加到了一整个，山药、土豆、红薯、南瓜、胡萝卜等块茎类的煮晚饭时放到电饭锅里顺便蒸出来，红枣也经常顺便蒸了，各种叶子蔬菜就单独烫一下再切碎碾烂。上午吃一顿，大人晚饭时吃一顿。每顿都是四勺米粉加一两勺奶粉，上午搭配的一般是鸡蛋黄加两三种青菜，如果有煮粥会把粥表面那层粥水拿来冲开，晚上一般是一种肉加一种块茎类加一个红枣和一种青菜。有尝试宝宝面，不过煮的都有点不太合适，吃的情况一般。对喝粥兴趣不大，不管是小米粥还是大米粥，可能是比较稠不好吞咽，鸡蛋黄也有腻嘴的问题。喂食方面表伯母来了后帮忙喂的要更好一些，不用分人抱喂逗，一大堆都能基本吃完

水果除了之前试过的香蕉、苹果、甘蔗，继续给尝了草莓、蓝莓、橘子、梨、龙眼等，都吃的蛮好的。生冷的水果比较脆，咬的很带劲，比如苹果，但是吃了容易不消化拉肚子或拉小块状水果，大部分时候还是蒸熟了弄成泥或软软的给吃

零食妈妈给买了手指饼干，可香了，一开始吃的时候会舔一下或咬一小口给砸地上弄碎，现在会大口大口吃，还会递给外婆奶奶等带的人嘴边要一起吃

喝水用吸管杯尝试后，发现莫莫还不太好控制力度，经常一吸一大口然后呛到，或者咬着吸管玩但是不喝，怕弄湿衣服着凉和避免呛到，现在还是用碗和勺喂的情况更多一点

拉臭臭大部分时间一天一次，只要别吃坏肚子都挺规律，便便性状也比较稳定。容易吃坏肚子的一个是生冷水果，可能导致拉肚子，要么就是着凉。另一个方向是连着吃鸡肉等容易上火的肉类，会导致便便变硬或轻度便秘

睡眠习惯变成白天只有中午睡一觉，一般睡一到三个小时，中间可能醒一两次，可以很快哄续上。晚上八九点吃奶睡觉，半夜一两点要醒一次给换尿不湿，凌晨五六点要醒一次换尿不湿和喂奶，然后睡到八九点才起床。好的时候一夜无事，闹腾的时候哄睡可能就要哭闹很久，半夜醒来也可能哭闹，偶尔还有半夜醒了不睡也不闹，自己在床上各种拱来拱去咿咿呀呀搞上一两个小时，带睡的人是挺崩溃的。如果睡醒来还想睡，一般就会哭哭，要哄了接着睡才行，如果睡够了就会乐呵呵的到处看，要把旁边陪睡的人连抓带挠又喊又叫的弄起来陪他玩

搬家后只要天气允许，上下午都会带出去溜达个把小时。小区里有非常多差不多大的小朋友，带出去时会互相交流育儿经验。不过莫莫不太喜欢跟差不多大的小朋友一起玩，更多的都想跟着三四岁的小朋友看他们跑来跑去、骑车、滑滑板车等。在外面坐不住，要抱着各种扭来扭去找他喜欢的东西，太活泼了。小区草地上有一些小动物雕塑，最喜欢的是大熊猫，总想去摸，非得抱着的人去踩草地到跟前去

在家里客厅铺上爬行垫，下面垫了个之前的薄床垫（类似褥子）避下地上寒气，再弄围栏围起来，就可以放心丢他在里面爬来爬去各种折腾了。一个月的时间，从麻溜的自己爬到轻松翻身坐起来，再到慢慢扶着撑起来跪着，到抓着围栏自己站起来，现在都能稳当站着踮脚去凑围栏外茶几上的东西，还可以扶着围栏或有人扶着的情况下迈步走了。小朋友这个阶段的变化太快了，一天一个样，现在抱着他坐都不乐意了，非得自己站着

上门牙两颗都萌出来了，白白的一条，比下面门牙要宽，现在可能是还没太长出来，看着中间好大一个空，两颗牙跟八字一样，等长出来应该会好。自己有时候长牙痒，上下牙磨的咔咔响，扶着围栏站起来时也喜欢去咬围栏磨牙，还好天天擦干净了的

想学说话，经常能咿咿呀呀冒出很复杂的好几个字的音，就是我们听不懂罢了。说的多的还是类似 ba-ba 的音，但是并不是都在叫爸爸，而且音调什么会有些许差别，可能是他自己的不同词语。经常会啊啊啊的大喊，不注意时会冷不丁被吓一跳

已经能听懂不少话并作出正确的反应，问爸爸妈妈在哪里，会扭头去找，问眼睛鼻子等五官，也能用手去指正确的位置（虽然有时候不高兴就不怎么配合去瞎指），家里房门上贴了有鱼的福和小鸡，问他鱼或小鸡在哪里，也能用手指向贴了的房门

笑起来超可爱，哭闹时就各种头大。好在大部分时间都是乐呵呵的，或者可以很容易逗乐，跟他捂脸捉迷藏、举高高、骑爸爸脖子等都可以乐的嘎嘎乱笑，给他讲卡片书上各种东西，学动物叫或念英文给他听，也非常高兴
