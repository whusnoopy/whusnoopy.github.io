Win7 RC bugs

2009年5月19日

很抱歉这一期依旧不是充满八卦和诡异的面试

用到目前, Win7 RC 出现的问题如下:

  1. Office07 的 Ribbon 界面无法实现按住标题栏拖动使其从最大化还原, 如果不是最大化的情况下, 倒是可以拖到窗口边沿使其最大化/左半/右半屏幕. 感觉是个 Bug, 果然 Office07 只是和 Vista 搭配的而已
    # 在安装了Office07SP2后,此问题解决

  2. 金山词霸会使得 Explorer 崩溃, 就是管理桌面的那玩意儿, 其实金山词霸一直有这个问题, 最新的 09 在打了 SP3 后, XP 下依然经常出现什么内存不能写啥的, 但是在 Win7 里错误比较隐蔽了, 压根就没报错是金山词霸引起的, 只是说 Explorer 崩溃, 要重启之, 然后继续崩, 陷入死循环, 一般我都在 Explorer 试图第二次重启前就把金山词霸关掉使其能成功重启了, 没测试这个死循环是否能在若干次崩溃后回复. 理论上讲关了屏幕取词和划词翻译不会出现问题才对, 不过实际只是降低了错误的概率

  3. 这个 截图 … WMP 的诡异情况, 回到 Library 模式再回来还是这样, 囧…

  4. 偶尔的开始菜单错位. 就是点开始按钮后, 出来的菜单下沿应该和任务栏的上沿在同一高度, 但是有时候这个菜单的下沿和整个桌面的下沿一致了, 诡异, 目前还不确定如何重现此问题

  5. QQ 的兼容性. 只要开视频, 就有一定概率整个 QQ 崩溃然后自动重启

另有问题求解: 如何添加 “使用 gVim 编辑” 进资源管理器的右键菜单?
