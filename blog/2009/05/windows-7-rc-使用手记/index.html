Windows 7 RC 使用手记

2009年5月17日

我随大流一起赞叹 Windows7, 身体力行在 beta 之前装过两个版本(只是不在自己的笔记本上). Beta 发布后 down 了个但是一直由于机器用到没停所以没装, 而 RC 发布后, 我和阿荣同时 down, 结果我的 32bit 没他快, 他为了发挥其 5G 内存的全部性能, down 了个 64bit 的 RC, 于是前几天做实验做郁闷的时候, 就在自己笔记本上装了. 是 “使用手记” 不是 “试用手记”, 是因为装好 Win7 后我就再也没回到 XP 下过, 已经是我的主系统了.

目前是 Windows7 Ultimate x64, 版本号 7100, 硬件系统为 ThinkPad T60, T5800(1.83GHz/800FSB/2M), 2G Ram(2*1G DDRII 667), 100G (Seagate 7200.2, 7200rpm/8M) + 120G (Hitachi 5K160, 5400rpm/8M), ATI x1300 (64M/64bit), SXGA+ 1400*1050, BlueTooth, FingerPrint, Infrared, Microsoft Wireless 1.0 Mouse. Windows 算出来的性能得分分别为: 处理器 4.9, 内存 4.9, 图形 3.6, 游戏图像 3.6, 主硬盘 5.2.

装好后驱动基本就搞定了, 有指纹, 蓝牙, 红外, PM 芯片(电源管理的) 等需要自己手动选下 Update, 也在直接联网的情况下搞定了, 其中一个小插曲是装了 PM 芯片的驱动后, restart 成了关机, 于是怨念了很久, 结果后来发现, 这个问题是因为 restart 后黑屏加掉电的时间有点长, 大概有 2s, 每次我都等不及直接 Power On 了. 鼠标是直接被识别了出来而且型号都对, 果然自家的就是好啊. 麻烦点的是显卡, 因为一开始看没认出来, 开不起 Aero, 于是去 ATI(AMD?) 官网去弄了个 for Win7 x64 的驱动, 结果死活装不上去, 等折腾了一段后再 Update, 就能自动认出来了, 很神奇很诡异.

由于平时用的 ThinkVantage 系列软件, 只有 Fn+F7, Fn+F5, 现在屏幕切换已经可以用 Win+P 搞定(flymouse 说 Vista 里开始支持, 但是我记得是没有的), 网络切换 Windows 自己也能很好搞定, 就都不用了. 唯一有点麻烦的是指点杆的中键, 我习惯了用这个来当滚轮, 而 Win7 没能自动搞定, 于是去 down 了 for Vista 的驱动来, 一切搞定, 没有装 Wizard, 因为平时也不用 Fn+F8 来切换. 按照网络上的说法, 去装了 HotKey 的驱动(其实我发现很多不装也可以用的嘛), OnScreen(没事还是需要看看显示的, 主要是音量大小和屏幕亮度几格), APS(保护硬盘的东东), 都是 for Vista 的, 没发现任何兼容性问题. 今天看大家讨论说风扇声音, 于是又去弄了 Power Manager 下来, 也是 for Vista, 依旧没发现任何兼容性问题, 没有跟网络上很多人抱怨的一样不能用, 只是, 我发现似乎这个要不要也无所谓了 -.-

然后说软件兼容性, 装好后先装的 Office, 由于只有 iso, 所以虚拟光驱也是必不可少的, 按照 “Vista 能用的 Win7 就能用” 的指导思想, 选的最新的 Daemon 4.30.4 Lite, 一路提示不兼容, 不管, 重启后还是顺利搞定, Office 也一如既往的顺利, 勾去了 Access 和微软拼音以节省空间. 常用的 QQ 2009, Windows Live Messenger 2009, QQ 拼音 2.0, QQ 影音 1.1, 都没问题, Firefox3/Chromium2.??? 也顺利的和 IE8 三足鼎立. 绿色版的 SecureCRT 也还能工作, 我的实验还是可以继续在旁边机器的 Linux 上跑的 :) 7zip 装上后有点小郁闷的是这个似乎分 64bit 版和 32bit 版, 区别是无法添加右键菜单? 而且如果需要关联文件格式, 需要 Run as Administrator 才能设置成功(其实也能理解, 因为修改系统设置了). 到目前为止, 还装了 gVim7.2(有一点小问题是似乎右键菜单 Edit with Vim 没添加成功, 用管理员模式重新安装了一遍依旧失败), MinGW(直接安装成功, 不过我试了下, sizeof(int) 还是 4 不是 8), 金山词霸 2009(我不多的正版… 居然默认是英文界面, 不过 Win7 是英文了, 也算自动识别了, 最多我改下而已), Nokia PC Suite, 迅雷(5.8.600 去广告版). 还有个大头, 一会再说.

再说 Windows7 的一些新功能:

  1. SuperBar. 就是传说中的超级任务栏, 确实挺爽, 不过默认的全图标层叠模式还是不够习惯, 适应了一天后还是改成了显示文字标签, 而且只有必要时才折叠. 窗口多的时候折叠还是比较好的, 其实就是原来的按组排列(似乎是 WinXP 加入的?), 只是这个智能一些, 只有在任务栏排不开的时候才折叠成一个. WLM 新版适应了 Win7, 默认就在任务栏上停着, 而且打开后就两窗口, 很不爽, 网络上搜了下, 用 Vista 或更以前的兼容模式跑 WLM 就行了, 于是改成 VistaSP2 兼容模式运行就回到右下角的系统托盘了.(你说这是个什么事…) 像 WMP 可以直接在任务栏的小窗口里暂停等操作对我没太大意义, 我都是快捷键 Fn+上下左右 搞定的.

  2. 改进的 Aero 效果. 像任务栏停留可以使当前窗口激活, 其余窗口透明化, 绚烂的 Win+Tab 窗口切换, 抖动窗口标题栏可以使其他最小化这些, 都只是 show 一下, 平时很少用. 但是 Win+方向键 和用鼠标拖窗口到屏幕边沿来最大化/左半屏幕/右半屏幕则是相当的好用, 比原来的双击标题栏好多了, 很适合双窗口互相拷贝啥的, 不过由于我现在不是宽屏, 分辨率也不够高, 半个屏幕能干的事还是太少, 所以一般还是双屏幕使用. (1680*1050 以上分辨率左右半边最大化应该就很有用了)

  3. Win+P. 由于目前还没连过投影仪, 只外接了一个 17LCD, 所以这个功能的先进性还没完全体现, 至少, 直接 Win+P 选 Extend 后, 就很自然的就将屏幕分好了, 而且分辨率都是自动选的最佳分辨率, 其余的几个模式也都用的很爽, 比 ThinkPad 自带的 Presentation Director 好用, 快, 而且不用不停选分辨率. 也许 Win7 接投影需要两边都较低分辨率时需要手动介入? 由于最近几周组会取消, 没试过还. 另一个很赞的就是现在按 PrintScreen 后直接截的就是双显示器合并的图像了. 按 这里 看效果.

  4. JumpList. 不知道怎么翻译这个好, 无处不在的超级列表? 从任务栏上点图标的右键, 已经可以干很多事情了, 比如 IE/word 等, 会列出最近的网页和文档, 在 WLM 上点右键可以直接切换状态等, 都不用二级列表. 在开始菜单里, Notepad 等也有一个可以点开的三角形来激活 JumpList 然后选取常用的功能.

  5. 图像矫正. 玩了一把, 没看出来啥不一样的. 好吧, 我也就是这个色彩辨别能力了, 虽然我总觉得 LCD 和我笔记本屏幕上的色调不太一致, 但是也调不对来.

  6. 高 DPI. 这个在现在的大屏幕液晶上应该很有用, 很多人都抱怨不习惯那么精细的效果, 字太小, 我这种高分屏控当然是不 care, 但是很多人还是不爽, Win7 直接能调 DPI 还是很爽的, 并且效果看起来要自然很多, 就跟在 CRT 上把屏幕分辨率调小了一样, 但是在 LCD 上也能依旧精细.

再来说几个比较诡异的东西:

  1. 分区调整. 本来我是没这个需求的, 结果小崔的电脑 C 盘 80G+, 本来是忽悠说拆成两个 40G, 一个 Vista 一个 Win7 吧, 结果早知道 PQMagic 不能用, 能在 Vista 下用的 Disk Director Suite 居然版本不一致导致注册机失败, 等我搞定后她已经成功把新买的硬盘挂到了主硬盘位, 把原来的那个盘挂新的托架上替了光驱. 于是, 这个东西还是我来用吧 -.- 跟 PQMagic 差不多, 用的很爽, 调整分区啥的似乎比 PQMagic 要智能很多, 会自动合并冗余操作. 本来我的硬盘是 12G(XP) + 20G(Work) + 30G(Funny, 音乐啊游戏啥的) + 11.1G(Bak) + 20G(Virtual) [以上为 100G/7200rpm 主硬盘] + 40G(Movie) + 40G(Temp) + 31.7G(Download) [以上为 120G/5400rpm 的从硬盘], 把 20G 的 Virtual 腾出来装的 Win7, 结果被别人说你干嘛这么多盘, 想了下也确实, 于是在搞定 Disk Director Suite, 并成功将 40G 的 Movie 扩大到 50G 后(抢的 Temp 的), 开始大脑抽筋决定把磁盘结构重新组织.
    于是, 把原来 11.1G 的 Bak 成功的从扩展分区合并到了新的 Win7 的分区上, 31.1G 目前装了一堆东西加虚拟内存(2G), 禁止了休眠(Hibernate) 后还剩下 16.4G 空闲, 应该是够了, 最多再弄一 Visual Studio 之类的上去. 把 Temp 的东西移到 Download, 然后所有空间合并到 Movie 并改名为 Media, Funny 上除了游戏的东西移到了 Media, 游戏移到 Work 后所有空间合并到 Work. 中间还把本来是逻辑分区的 D/E/F 把 F 合并到 G, 把 D/E 合并后改为主分区, 这些操作需要重启, 然后发现黑屏的 Win7 还没 WinXP 好看, 点 这里 看照片.
    于是, 现在的盘符都乱了, 按照磁盘物理顺序, 目前是 XP(12G, G 盘) + Work (50G, D 盘) + Win7 (31.1G, C 盘) [以上为 100G 主盘] + Media(80G, E 盘) + Download(31.7G, F 盘). 本来想去败家个 7200.3 的, 结果 Willow 说他买了块 7200.4, 再去查了下, 原来我 YY 了这么久的东西都又更新了一代, 可怜我那 7200.2 的 100G T__T. 貌似最新 7200.4 的 250G(单碟) 400+, 320G 600+, 500G 800+, 口水一下, 如果发现以后还能告诉下电影, 就换… 喵滴… 不过, 按 Win7 的评测, 似乎我目前的系统瓶颈是显卡? 真怨念当时选的 x1300, 不过当时 x1400 要贵一千大洋啊, 不合算 -.-

  2. 游戏, 游戏. StarCraft 当然是还要玩的, 虽然现在还是玩的一如既往的烂, 结果 XP 下不用任何兼容性的, 在 Win7 下非得把所有的兼容性选项都勾上, 为了安全起见, 我把系统兼容都选成了 Win98, 终于, 跑的真爽, 只是还是有点类似花屏一点的出现在水体效果上? 不管了, 别的都好好的. WarCraftIII 昨天试说不能在英文版的系统上跑, 上网搜了下有说改注册表把语言改下, 觉得不靠谱, 果然又搜到说那样后 Library 的搜索功能失效, 然后也有说复制一份注册表键值的, 结果最狠的是把魔兽的 Game.dll 里某个 16 进制位从 74 修改为多少来着, 觉得靠谱, 修改后搞定(为了这个特意又把绿色版的 UltraEdit 弄起来了, 用的也好好的, oh yeah!). 硬盘上最后一个大游戏 CS 貌似是本科毕业的时候装上去全班群殴的? 进去后就不停的抖, 当时为了腾硬盘, 毅然删掉了, 反正那个版本也有点问题, 也懒得管了 -.-

最后扯点别的八卦… 似乎我总是喜欢在赶 deadline 的时候干别的来分散压力, 比如当年做 MCM 的时候我就还把 oak 的界面给改了, 似乎 oak 现在的界面就是我在 MCM 的 96 个小时中搞定的. (YangJing 和 ZhangMin 不要 bs 我… 也许当时我不干这点私活, 我们就 outstanding 了?) 然后现在这个 Win7 也是上周末被老板殴的一塌糊涂, 然后周一被 MSRA 面的郁闷的要死, 接着发现洗澡的香皂不见了后, 郁闷的要死在周二时跑数据跑烦了, 于是数据继续放另一台机器上跑, 我抽空装的.
