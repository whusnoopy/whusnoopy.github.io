又过了一个星期

2006年12月11日

这一周好像过的还是非常充实的, 事情差不多都做完了.

传说中 14 周考的 Java 没有考, 奇怪, 估计也就是下个星期了吧.
选修的作业交了, 反正老师也没讲什么, 也就随便弄了以下, 排版排的很 PP. 操作系统的实验报告, 跟别人不一样的使用语言来描叙测试数据和结果, 省了很多纸, 并且觉得也弄的要清楚一些, 也提前搞定了.

ACM/ICPC 的海报没有如期完成, 不过今天晚上已经做了个很不错的 Demo 了, 网站的改版今天已经全部搞定了, 就是那个配色比较麻烦, 搞定就好了. TC 的联系也继续中, 只是宣传没有原来好了, 借不到教五, ft.

看完了死亡笔记, 决定这个学期再也不看这种长期性的东西了, 太浪费时间, 宝贵的生命还可以做其他很多事情的.

分类：碎碎念 标签：WHUACM、大学生活
