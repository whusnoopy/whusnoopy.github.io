2016 年度盘点（完整版）

2017年2月12日

补全 2016 年度盘点（简略版）

莫莫

2016 最大的变化就是莫莫出生了，生活重心也随之转变，各种照顾吃喝拉撒睡陪玩，各种买买买。因为照顾莫莫的人变的还是有点频繁，老实讲感觉并不是很好，总觉得我们好像还有很多事情并没准备好，这种情况下把莫莫带来这个世界有点不负责任，但是很多事也确实是只有遇到了才能知道有这回事并去解决

关于莫莫的成长细节就不在日常的记录之外再多讨论。整体上除了有一点闹，其他都好。笨狗觉得莫莫并不像部分家属担心的有很多问题，吃饱穿暖心情愉悦就好。比小胖子们瘦，但是也没有超出正常区间。希望莫莫能一直开心自由的成长，我们替他解决物质问题，在心智成长上给予正确的引导，剩下的还是看他自己，不要以大人喜好去强行安排他的人生，他的人生应该他自己去享受

工作和学习

看了下 git 记录，全年合并提交 1141 次，大部分工作还是跟重构相关。这是个跨了一年的坑，最后的结果还算凑合，不过过程中略失控，太漫长

一开始只想把前端一个超大的 css 文件拆成 less，把通用的组件、颜色和尺寸都变量化，这样后续要改都能一次改掉所有的，新增也能按统一规范来新增。拆的过程中发现很多东西并不那么好拆分，有大量的 ID 选择器，也有很多类选择器被用在 js 里，干脆重写

一边用 Less 拆分重写样式表，另一边熊也先把一个超大的 js 拆成若干小文件，至少维护难度低一点。拆 js 过程大家对之前的结构组织都没法忍受，也打算重写，这时候过早为未来考虑，说以后大屏都统一成一套（Web、千牛电脑版、大屏手机直接用浏览器），小屏统一成一套（手机千牛、手机淘宝，手机浏览器），后端接口也要统一成 RESTful 的，那么整个代码结构和逻辑都要大改

先把一些独立的页面先切到了新版，也保证了千牛上的一致性，然后从商品选择器这个大控件下手，开始切部分页面，里面逻辑比预计的复杂太多，过程中也考虑了很多之前的坑和新加的需求，整体进度从这时候开始失控

七月初新进一个设计师，花了比较多时间去沟通我们的产品是怎样的，一些细节都是怎样的考虑，把已经做完的往新设计上靠，要做的事情也往这上面走，八月份这位设计师又走了，很多事情又不知道该怎么推进，还是回到先实现功能再考虑样式适配的路上

十月份把已有功能基本开发完成，开始做各种测试和样式适配，美折里的产品细节远远超过之前自己体验的和预计的，到处都是一些神奇的坑，填坑填的很痛苦。等把功能测试和样式适配完成，并做了一堆浏览器适配后，在 2016 结束前终于全量上线

全年花了很多时间在招聘上，走了很多弯路，还好在年末算是走入一个比较靠谱的轨道。直接带了两个新同学，间接算也还带了一两个人，整体上比预想的要好，年末时 Gardon 加入，感觉子煜已经带上道了，就把想弄前端的他转给了 Gardon

没有花什么时间去成体系的学什么技术方向，更多的是把前端开发的各种技能给点上，同时实践 js 的各种坑

在管理和企业文化方面看了一些书，但是觉得目前还用处不大，该有的总会有的，对付不来的东西似乎一时半会也推不动。不过倒是认识到了一些自己以前没注意的缺点，比如只关注过程觉得自己努力把事情做好了是不够的，结果才重要，没有结果过程做的好意义也不大，当然如果要说过程就是学习经历不要在意结果，那么这个学习经历也是有学习的结果的，比如不要去抠很多细节，该放的要努力放手，把握好关键点，放得出收得回就行。另外就是要更重视沟通的方法和技巧，跟不同的人打交道的确有太多不一样的方法，就算是能直来直去的，技巧好点也会事半功倍

生活和娱乐

2016 年的第一天收房，拿到人生中属于自己的第一套房子。年初花时间弄了宜家的一大堆家具并在春节前坑爹一起装完，后面没多久把窗帘都弄了，五月份补齐了剩下的一些家具，618 前后把冰箱洗衣机两个大家电搞定，夏天把两个定制衣柜搞定，阳台包好，阳台柜弄好，十二月再弄了电视，另外把书房改成卧室，准备好搬家

跟公司出游，莫莫出生前去了一次菲律宾长滩岛，十一前去了一次上海迪士尼，夏天还去漂流了一趟。自己则就是杭州市区过年前后各种陪家长走了一下，并没有点开多少新的地图，倒是宜家去了好几次，不过不是当主题公园在刷，而是正儿八经在买东西

莫莫出生后各种操心和瞎操心，瘦了快十斤，端午节时家里出了些状况喵带着莫莫回老家呆了一个月，笨狗一个人回杭州后身心疲惫了一阵（本想说大病一场，好像也没啥，就是各种憔悴），习惯后就好多了

念叨了一年多换车的计划也没成行，一方面是租在城区停车不便，周末都没开车回去，换车的主要目的是周末带莫莫出去玩，这个就意义不大了，另一方面是好像也没那么强烈紧迫的需求，也没空去看车，搬家后再严肃点考虑这个问题吧

数码和败家

有莫莫了以后就没怎么给自己添置设备和败家。喵的 iPhone 6 因为 16G 存储各种捉襟见肘，等 iPhone 7 一发布就定了一台 128G 的给喵，是个惊喜，推推拖拖后面也还是开心的用起来。老爸说他的红米 2 电信版屏幕出了问题，十一前给换了个红米 Note 3。喵妈妈十一后在这边带娃辛苦，生日时没买别的，也买了个红米 Note 3 替换掉了之前喵淘汰给她的红米 Note 一代，刚好在这边能用上笨狗的电信副卡，回去喵爸换了电信套餐后也一起用电信了

其他的很多小玩意儿都是为莫莫在买。四月份莫莫出生前买了个小米空气净化器，等年底要自己的公司周年礼物时还是要了个小米空气净化器，八月份准备请阿姨带莫莫前弄了个摄像头，方便上班后看看莫莫都在干啥

莫莫的奶粉尿片辅食这些都是例行项目。童车在五月份又买了个伞车但是似乎依然买大了，叠起来还是不够方便。其他大件有了各种教训后开始进入后爸模式，没那么多冲动买的念头。在双十一前后定了两年的巧虎，每个月收点玩具和小册子也还好的

各种大支出基本就是折腾新房，各种买家具买电器定制装修。还有就是各种家属在老家和杭州的往返路费，有莫莫后本来就要来去的频繁些，加上一些状况更多了不少交通支出

Gardon 入职时要台式机，顺带薅了一枚 i5-6400 替换之前置换客服机的 G1820，明显不是一个档次的东西，这样在家开台式机干活也挺爽，配合 Ubuntu@Win10 开发环境也不在话下

还在用随手记记账。例行的收入还是工资奖金和部分理财收入，继续没折腾股票等有风险和需要花时间的事。公司下半年新三板挂牌后分了一次红，似乎离想象的有点远，但仔细算算也就这样，估计还是想的太美好忘了实际情况到底是怎样。因为莫莫出生和搬新家，倒是从两边家里收了一些大额礼金，这也是个奇怪的收入方式。涨了些工资，加上公积金，才不至于说到手的钱都花光光。整体的资产表，加上各种非例行的收入才算是扭成正的外加些盈余。买房还是个超大的坑，而且对未来的略保守，现在回头看也许该把坑挖的更大一点才对

2016 年度盘点（简略版）

2016年12月31日

每年年末的盘点还是要保持下去，不过看起来不像是能把完整版写完的样子，去年也是一样

买的房子交付了，年初装家具，全年都在补充各种家具电器等，有莫莫了还是散味充分点，打算在 2017 年年初搬进去

莫莫出生，整个生活重心都开始围着他在转。端午前后因为家里各种原因，喵带着莫莫回老家呆了快一个月，发现还是多愁善感舍不得，自己回杭州后各种紧张终于压到一起，差点大病一场。G20 时交通基本瘫痪，在家陪了一周多。带莫莫的人也来回换，其实并不是特别希望换太勤。各种买东西也是围着莫，奶粉尿不湿辅食玩具，衣服什么的都是喵在弄

有莫莫后基本就没有自己和喵的假期了，在莫莫出生前蹭公司的年度出国游去了一趟菲律宾的长滩岛（Boracay），九月底时公司团建去了一趟上海迪士尼

工作上，去年年底开的重构坑，搞了一年也只算个基本完工，很多东西在过程中都是在重写，整个底层也有太多变化。带了两个新人，比预计的情况好一些，有帮手了可以有更多的想象空间

想换车，但是似乎客观上并没有那么大的紧迫感又没换成。没有添置什么自己想要的大小玩具
