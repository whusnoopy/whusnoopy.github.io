96's Final

2006年9月14日

This afternoon we did a practice contest, problems and data are come from the ACM/ICPC 96’s Final Contest. There is so many things looks strange, the English to draw the problems is hard to understand, we did a hard work to read and understand, it makes two problems which are very easy to pass be passed later than our estimate.

I got some reply strange either, a problem I used double to check the feasibility and got a Wrong Answer, but used float to got a Yes. Then another easy problem reverted a  Runtime Error for more than twenty times, because there is a mistake about the means of that problem others told me, I checked both \n and \t for the end of input, actually the \t might be 0(zero), so I got more than 700 minutes penalty, sigh~.

Finally, although there is a good result as we hoped, but we still be the winner, 96’s Final is too old to the modern contests, the style of problems had been changed hugely, as I can get a better score on those contests.

盘点自己的2005

2005年12月31日

2005年的第一天,睡了个舒服的懒觉后和室友压了小半天的马路,从武测北门出去,绕道街道口回南门,然后去英语机房上网.

2005年的第一个月,开始大学的第一轮考试,乱七八糟的过了.不好,但是也没挂,最担心的电工花了一个下午就弄了81,真是笑话.体育破天荒的上了90,赞自己一个.

2005年第一个月的最后,回家过年,去看望了一下那些不幸复读的同学.特意去看了看猫猫,可惜也只是一个中午,2005年唯一的一次见面:(

2005年的春节,居然还能收到压岁钱,^__^.过年的时候在老家被要求喝酒了,两斤多米酒下肚,第一次人醉,家里的米酒还是比白酒好喝多了,啤酒也还是次了点.

2005年的春天,总结大一上的堕落,决定加油,但是还是在颓废.去武大看过樱花,看过阔别多年的人山人海.重新开始写程序,参加校赛,给自己的成年生日礼物是一个不是很开心的二等奖.感情上,继续给猫猫写信,从来不期待回信的写.

2005年春天的返校列车上认识了一个可爱的MM,在一个多月频繁的电话和接近一个学期的信件交往后,与其失去了联系.也许,我们本来就是两条不应该相交的直线,作为过客,在某一次擦肩而过后成为朋友,然后在另一次与另一个人的擦肩后又成为路人.

2005年的夏天,写了很多代码,没干什么特别的事情.一开始是在写C语言的大作业,一个很简单没什么算法的题目,写了1.6K行以上的代码,很自我膨胀了一下,感觉很完善的功能,却最后总评只有86.玩了一小段时间的魔兽世界后,结束了乱搞的期末考,开始暑假的集训.

2005年的真正的夏天开始的时候,已经在集训队的机房里面享受空调了.妈妈在长沙动了一个不是很大的手术,但是跟很多蹩脚的电视剧一样,家里人没告诉我,当我知道的时候,手术都完了,去了一次长沙,看了看爸爸妈妈,然后很快回到集训队继续单调的暑假.

2005年的暑假,是在机房忙碌并充实的度过的,认识了很多值得我去学习的师兄师姐,认识了我的队长,这个影响了我2005年大半年的人.队长一直是我比较钦佩的人,我钦佩他的学习态度和学习方法,觉得跟在他后面是一件很快乐的事情.暑假,学会了一些算法,写了很多简单题的代码,参加了很多次单挑或者群挑,但是从来没觉得我处于下风中,一直认为我是可以很光荣的进入一队的,和队长一起征战ACM的赛场.暑假,大家一起会在饭后玩玩小游戏调节一下.暑假,吃了不少次的饭,喝过酒,也曾经背集训队醉酒的MM回学校.

2005年告别夏天的那一段时间是灰色的,只是因为自己的一些谦虚和一个无法判断的师兄的原因,一个现在我不想去评论的老师将我弄出了一队,并且也没有给我任何参赛的机会.当得知我只能以替补的身份出去公费旅游的时候,我的天空,一片灰色.在告别夏天的日子里,我变得异常无奈,异常的践踏自己,什么都没干,甚至到开学后也什么都没干.

2005年下学期的开学,只不过提醒了我一下以后除了机房还可以去教室.在9月的某一天和队长两个人去找了一套POJ以前的试题,写的很爽,很赞队长和我一起写的那个字符串密码的处理,这是我2005年最开心和最得意的事情之一.

2005年的秋天,出去玩了两个地方,去拍了不少照片,但是,很少有我.在四川的时候,只有最后一顿吃了一次比较辣的川菜,而很郁闷的成绩也没能吃好.在杭州,场外的我看着两个队长,最后只是一声无奈的叹息.西湖苏堤上,笑的那么难过的我如同身后的雷峰塔,只是一个悲剧.没去的北京,Cowork在那里失常发挥,对自己,是一种嘲笑,也是一种鼓励.整个秋天,自己都是笼罩在一种悲哀的气氛中的.

2005年秋天的尾巴上,被猫猫认可,这是2005年最开心的另一件事情.每天睡觉的时候,能有一个远方的人值得想念,也是一件快乐的事情,只是,整个2005年,就见过猫猫一次,前后不到4个小时吧.

2005年的冬天,一事无成,经常出去跟KMXS一起散伙,一次又一次的散伙.然后把以前那个让我郁闷了半年的老师下课了,开始策划自己2006年的ACM之路和武大的2006年ACM之路.

2005年的最后一个月,帮队长找到了MM,但是在最后一个月的最后几天,队长失恋了.我能理解队长为什么会那么做,因为很大程度上,我们都注定了同样的命运,有同样的悲哀.最后的3天,和队长喝了两次酒,很快乐,也很不爽,因为我们说的都是那么沉重的话题.

写在2005年最后一天的最后几个小时,盘点一下自己的一年,什么正事也没干,但是也经历了很多应该经历的事情.Wish myself.Bless自己的2006.

回忆一下偶们的SCU之行吧

2005年11月16日

本来应该早就发了,但是一直没心情过来

发信人: iBook (不说了,说多了都是眼泪), 信区: ACM_ICPC
标 题: 回忆一下偶们的SCU之行吧
发信站: 珞珈山水BBS站 (Tue Nov 8 13:19:26 2005), 转信

4号早上快11点才出成都火车站吧,火车晚点了近一个小时,一起坐T247过去的华工,国防科大
,地大一起上大巴到了川大的龙泉校区,在高速公路上飚了一个多小时,晕...

然后在宾馆睡了一下午,晚上上网,还在嘻嘻哈哈,在SCU安排的网吧里遇见了SZU,HUST,FDU,P
KU等等学校的人...走的时候拍了几张别人的PP,睡觉,等待5号的练习赛

5号上午随便转了转,然后回去看抽签结果,女队28,男队82,女队的左边依次是南开,浙大(这
个不是很清楚了),川大T6,上交outel,THU J TEAM(这个中间应该还有一个),男队的对面是国
防科大,右前是BNU_SHISHI(BT的两女一男组合),右边是SZU(深圳大,正式比赛中干了件很BT
的事情...),后面有PKU_T4(女队,后来的第四还是第五吧),在KMXS的视野范围内,还有后来的
rank1 THU1

拿奖面是6/70的金牌,14/70的银牌,20/70的铜牌,不能不说很多,ICPC的按规矩,只到RANK10

练习赛一开始按照正规比赛的规定来操作,替补和教练都在场外,看rank的时候无数的队一开
始就过了A,然后是一些队很快把B也过了,BNU_SHISHI只过了B然后就准备闪人了...过了大概
一个小时的样子,允许替补和教练随意入场,去看了看题,A是一个A+B,纯粹是试机器的...B没
注意看,题目的经典解法貌似是DP,但是O(N^3)会超,最后是O(n^2*log2*n)过的,当时无聊看
卡的时间和内存,有10^10的时间,32M的内存,后来问SCU的judge,最后的正式比赛内存是128M
,时间还是要看算法(这点没仔细注意,有些吃亏)

练习赛中也有无聊的人问裁判my chair is broken,呵呵,练习赛的时候看了看气球,一共9个
题目,A红,B橙,C黄,D绿,E紫,F青,G蓝,H白,I花(个人感觉这个设置很失败,因为白色的花纹稍
微远一点就看不清楚了,容易被误导)

5号晚上大家都比较早睡觉了,准备第二天的考试啊,晚上睡觉的时候跟dongfangxu说的时候
还有说到在SCU应该是2题很快才有希望拿牌应该,3题快的话应该是银牌,我们的水平应该是

第二天早上7:00闹钟响的时候马上就起来了,然后电话通知其他所有的人,走了比较远的路去
吃早餐,然后回来拿东西,入场.

9:00比赛准时开始,我在这边用老杨的手机给小强做直播,前面20min没一个队敲键盘,到40mi
n的时候比赛场馆还是非常的安静,然后在大约47min开始有人过题,到1h的时候过了2个C,两
个I,但是那个I距离远一点很难看清楚,然后过的就有点乱,不过一般还是C或者I,我们的队伍
却一直没有动静,在场外有点急...

到大概2h的时候场面就比较乱了,虽然一直没什么人在敲键盘,但是这个时候有好几个队过2
个了,最BT的事情出现了,SZU过了A(全场第一,最后也就是2个队过A),PKU_T4过G(全场第一,
最后3个还是4个过G的),BNU过B(全场第一也是唯一),KMXS旁边的队伍都是过的莫名其妙的题
,并且都是那种全场都几乎没人过的,BNU过B的时候T4已经2个了,而我们一个也没有,这个时
候大概是2h30min了,看KMXS的dongfangxu一直在旁边算东西,mast和knuthocean轮换上,我看
的rank一直有了5次I的WA,HYZ有3次I的WA,真是郁闷

178min的时候KMXS一共7次过了I,当时场上是过3个的有几个队,过2个的大概10多个吧,我们
过I排最后,37左右,这时我们已经看到题了,G能看懂意思,但是感觉比较麻烦,C题目非常短,
但是看不懂意思,看他们就那么一直卡上面了

一开始过2个的队伍都是以前没注意到的,比如北方交通,比如南航,莫名其妙,SCU,ZSU,PKU,T
HU,SJTU,FDU等都是相对比较晚才过2个的,后来的局面还是比较符合惯例的,THU1不急不慢的
过了4个,PKU的三个队依次过了2个,T4反倒在前面,SCU过3个,然后好几个学校也3个了,T4也
3个,最后一个小时rank不更新,只能看场上的气球了

最后就一直守在KMXS这边了,看BNU_SHISHI不停的过,B,I,C...真是BT,SZU在过掉A后把I也过
了,我们过I后不久国防科大也过I了,并且因为罚时少在前面,PKU_T4过了3个,G,I,E,突然还
来了一个C的黄气球...我忙发***给小强,快完了发现原来插错了...

最后封版,去rank那里看才知道SJTU居然最后半个小时过2个到第二了...最不幸的是BNU,3个
的最后一个(过的比较晚,第一个过的居然是3个小时左右的B...),银牌第一...过2个的一共
有25左右吧,HUST的两个一个22,一个24的样子...都是铜牌前面,最后还有大概近30个队一个
都没有AC...(无语的SCU)

当天下午去川大本部看川大博物馆,就是我和带队老师去了...很不开心,晚宴上也一直开心
不起来,虽然表面上还是嘻嘻哈哈的...

晚上去吃了一次麻辣烫,要回来的时候居然还遇见PKU_T4在同一个地方happy...12点左右回
去到组委会拿到了Honorable Mention,也许是意料之中的吧,但是居然连一个牌子都没有就
太...

就这么回来了,很无语,很无语我们的表现,很无语SCU的题目设置.

希望co-work能在PKU考好,希望新的KMXS能在ZJU发飙...
