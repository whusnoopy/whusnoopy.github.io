不说毕业, 因为怕哭

2008年6月21日

不要奇怪为什么一直情感丰富的我到现在都对毕业只字不提, 也许有因为我去看了好几年的毕业晚会麻木的因素, 但是, 最重要的, 是因为, 一回忆, 可能就只有泪流满面.

就跟梁伟说的一样, 每天, 上网, 把各大网站扫一遍, 看校内上同学们的毕业感言, 看那些我们搞怪和醉酒的可爱照片, 但是, 看似狂欢的镜头里, 总有无尽的感伤和留恋的眼神. 不想提毕业, 因为, 毕业就意味着别离, 对很多人, 可能就是一辈子的别离. 我们有网络, 有电话, 可以很方便的联系, 但是, 我们再也不会回到原来一起在宿舍门口每人一碗饭吹牛聊天的日子, 再也回不到一排宿舍一起同时玩一个游戏的场景, 不能一起打球, 一起出去玩, 一起疯, 一起对路过的美女评头论足.

因为手摔了的原因, 没能去参加毕业晚会, 没能去一起第三次班搓, 去不了, 也是因为我害怕. 看别人的毕业, 虽然伤感, 但是, 那终究还是别人的, 那些哥们一般的师兄们, 毕业了我们也还是在一起. 我们自己的毕业晚会, 不敢看, 里面有太多熟悉的人, 熟悉的场景, 可能不到离场, 我就会泣不成声. 我们的散伙饭, 千言万语, 都会哽咽, 最后一句 “兄弟, 保重”, 闷掉一杯酒, 也许才是最好的表达.

捐款指南 - 工行往红十字会汇款

2008年5月14日

以下部分内容为武大特定, 但是大体上是全国通用的, 请看到的同学多分享一下, 帮助我们的一家人.
另: 献血请拉开批次, 每个人献血后都要过六个月才能献第二次, 且血液中心的储存能力是有限的, 真正的用血高峰是几天后伤员大量救出时.

–分割线–

  1. 校内的各工行应该都是储蓄所, 无法对单位帐号进行汇款
  2. 目前据我所知武大周边就是劝业场那个工行洪山支行可以汇款给中国红十字会总会, 且该行有专门开辟救灾汇款绿色通道, 在二楼
  3. 捐款不收手续费, 但是流程有点慢, 建议一起捐, 减轻银行工作压力

去银行, 在大堂询问保安, 填汇款单, 跟一般的个人汇款单不一样, 大堂里有服务台有发给单位汇款的单子
不用排号, 直接上二楼, 往一楼出口那个方向走, 右手边会看到有一个窗口写救灾捐款绿色通道的大字, 就是那了
捐款不收手续费, 捐多少就是多少, 汇款过程感觉有点慢, 所以推荐大家最好是收集起来派代表去(今天我很无耻的一个人去捐了那么点钱, 感觉在耽误别人时间 -.-)

单子上要填的东西:
汇款人姓名, 汇款人住址(住址写武大地址, 长了怕写不下, 地址用来收可能的捐款收据)
汇出地: 湖北省 武汉市
汇出行名称: 工行洪山支行(这个不是全称, 但是地方太少只能这么写)

收款人全称: 中国红十字会总会
收款人帐号: 0200 0010 0901 4413 252
汇入地: 北京市
汇入行名称: 工行北京分行东四南支行

汇款金额大小写
汇款用途: 地震救灾
汇款方式: 普通

身份证号码, 联系电话, 汇款人签名

vimrc 配置文件

2008年4月2日

这玩意儿可长可短, 但是这些一般还是必须的了, 过了这么久, update 下自己的默认设置. " 后是注释

set nocompatible " 非 vi 兼容模式
syntax on " 色彩高亮
set number " 显示行数
set ruler " 显示当前位置于右下角
set backspace=2 " 设置 backspace 模式为标准
set showmatch " 显示配对括号
set incsearch " 增量查找
set ai " 自动缩进
set si " 智能缩进
set cindent " C 风格缩进
set tabstop=2 " Tab 宽度
set softtabstop=2 " Tab 宽度
set shiftwidth=2 " Tab 宽度
set expandtab " 输入的 tab(t) 均转换为对应宽度个空格, 在 Makefile 等必须是 t 的文件中会保持是 tab
set nowrap " 不要跨行
set smarttab " 智能 tab
set fileencodings=ucs-bom,utf-8,cp936,gb18030,big5,euc-jp,sjis,euc-kr,ucs-2le,latin1 "字符编码
set statusline=%F%m%r%h%w [FORMAT=%{&ff}] [TYPE=%Y] [ASCII=%03.3b] [HEX=%02.2B] [POS=%04l,%04v][%p%%] [LEN=%L] " 状态栏格式
set laststatus=2 " 一直显示状态栏
" 插入模式切换
map <F9> :set paste!<BAr>set paste?<CR>

如果需要在 Linux 里将 vim 做默认编辑器, 在 /etc/environment 里加入下面一行

EDITOR="/usr/bin/vim"
