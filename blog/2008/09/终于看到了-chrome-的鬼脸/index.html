终于看到了 Chrome 的鬼脸

2008年9月5日

不过依然没看到崩溃的那个笑脸

看到鬼脸的方法(不知道别人那是不是可以):
g.cn/music 下随便打开一首歌试听, 在试听的标签(如果是独立窗口, 左上角按钮使其为标签, 此步骤不一定必须) 中开启 JavaScript 控制台, 地址栏右边那个按钮 > 开发人员 里找, 等一会, 就有鬼脸了

分类：技术手记 标签：Chrome
较早一篇 Google Chrome 的不爽和疑似 bugs 较新一篇 我想我是该快点离开
