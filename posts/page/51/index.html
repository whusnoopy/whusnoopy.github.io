Great People Know Great People

2008年10月30日

曾经在 Google 北京大楼里随处可见这句话, 貌似 Kaifu 同学也在他的书里经常提到这句话, 我个人也是这句话的强烈推崇者, 历史上还有一个比较臭名昭著的同学也很喜欢这句话, 他的名字叫阿道夫.

扯远了一点, 事实上这句话确实很赞, 非常非常赞, Kaifu 同学翻译成中文时说的是 “一流的人只跟一流的人一起工作”. 跟和你同 level 的人一起共事是一件非常愉快的事情, 你们说话, 沟通, 都是一件轻松的事情, 一个眼神, 一个手势, 就能表达出你们想要交流的意思, 在讨论问题时, 只要随意一句话的提点, 对方马上就能明白你的思路继而一下子打开局面. 你们兴趣相投, 会对技术或者新奇的玩意有着疯狂的兴趣和好奇心, 工作之余, 也会可以有大量的时间粘在一起, 至少, 开 Party 或者一起玩不会冷场. 你们的思考模式一致, 也都有宽阔的胸怀, 不会互相猜忌怀疑, 对任何事情不会有所保留, 我是指技术或者类似的东西, 不是隐私.

跟比你高 level 的人一起会非常累, 非常非常累, 因为你需要随时跟上他的脚步, 而他绝对不会停下来等你, 事实上, 你们的距离会一直保持, 并且有可能越来越大. 当然, 通过学习和努力, 进入到那个层次, 跟那个层次的人一起讨论, 就会发现是一个全新的境界, 而在这个境界之上, 还有更玄妙的 level. 假设 level1 最低, 当你处于 level1 时, 你会觉得 level3+ 的人都是牛人, 而你到达 level2 后, 就能区别出 level3 和 level4+ 的不同之处, 当你是 level1 时, 你看一个 level10 的, 觉得他是 level3+, 你们中间至少隔了 2, 但是不知道到底是多少, 而当你到 level3 的时候, 会很失落的发现, 原来那个人是 level8+ 的, 你们中间至少隔了 5, 何况那个家伙也还是在不停的进步.

跟比你低太多 level 的人一起会更累, 特别是对那种又愚蠢又勤奋的, 有关这个桥段, 貌似是伟大的二张德国军队理论, 说跟你并肩战斗的最好是又聪明又勤奋的, 其次是聪明但不勤奋的, 实在不行, 那就愚蠢且懒惰吧. 最怕的是又愚蠢又勤奋的人, 不仅不能有任何帮助, 反而, 他比敌人更危险, 这样的人会严重的拖累你, 拖累你的团队.

Great people know great people, 很喜欢现在周围那些 great people, 不管是在什么方面, 对某些人, 就是会有自然的好感, 哪怕对自己而言他似乎什么都不知道一样, 但是, 不喜欢身边的很多让自己觉得很累的人, 就算他是一个何等牛人, 在我眼中, 他还是什么都不是. 很怀念曾经共事过的那些 great people, 那种畅快淋漓感觉, 现在却是多么的难得, 那些曾经一起引导我成长的 great people, 也都走了, sigh.

ps. 最近超级不在状态, 这个贴写了至少 10 天, 分了至少三次才写完, 思路完全乱掉了.
ps2. 季节更替, 小心感冒, 貌似我已经感冒加发烧了

通过 DreamSpark 申请正版微软软件(欢迎分享, 拒绝商业目的使用)

2008年10月22日

微软全球范围内对学生的一个优惠, 可以免费使用以下收费软件
Visual Studio 2008 Professional Edition
Windows Server 2008 Standard Edition
SQL Server 2008 Developer
Expression Studio 2008
XNA Game Studio 2.0
XNA Creators Club Online
IT ACADEMY STUDENT PASS
Visual Studio 2005 Professional Edition

本来免费的那些 Express 版当然也可以直接免费下载和使用, 下面是获取方法, 请各位同学申请到序列号后严格遵守许可协议, 只是自己学习研究使用, 不要散播, 特别是不要用于商业目的, 曾经有人在 taobao 上叫卖序列号, 现在那个学校的所有邮箱都被封杀了

以下是申请 DreamSpark 的流程, 建议全部在 IE 中完成, 并通过校园网使用俱乐部代理或直接在实验室网络进行, 不然网页显示或者相应认证可能会有问题, 直接用宿舍网很多页面慢的刷不开, 电信的会提示 IP 范围不对

  1. 去 http://mail.whu.edu.cn 注册个武大的邮箱, 曾经有外面的可以免费注册的, 但是已经被封杀了, 别的学校同学请用自己学校的 edu.cn 结尾的邮箱
  2. 登录 http://www.msuniversity.edu.cn, 在导航栏上选 “软件下载”, 或选子菜单中的 “DreamSpark微软学生软件资源”, 点页面最下面的 “点击进入”, 右边的介绍链接都无效
  3. 在新页面中选 “此处” 开始注册和验证, 注册过程略
  4. 注册完成后, 选进行学生身份验证, 发一封邮件到邮箱, 同意许可后进入激活页面
  5. 复制邮箱里很长的一个验证码去激活, 会得到确认消息, 然后去 “进入下载”
  6. 现在看到的页面就是收费软件的下载页面了, 速度能上 1.5M, 在迅雷上或者哪里随便下一个也一样, 软件介质没问题, 我们只是要正版授权而已
  7. 在自己需要的产品中选 “申请 Product Key 激活软件”, 新页面中选 “Sign in”
  8. 用自己的 Live ID 登录, 就是平时登录 WLM(MSN) 用的那个, 如果没有, 去注册个, 或者去把前面那个 mail.whu.edu.cn 的邮箱注册成 Live Passport, 在 www.live.cn 完成即可, 很快, 那个那个图片验证码很有点 xxoo, 我换了几个才找到个认识的
  9. 接下来出来的地图上选 Asia, 右边下拉框选 China, 然后选 China-CERNET, 点 “Select and Continue”
  10. 弹出来的对话框输 mail.whu.edu.cn 的邮箱名, 就是 4 里用的那个邮箱, 密码是步骤 5 里面那个巨长的验证码, 直接拷贝粘贴
  11. 自此完成验证过程, 回到 6, 或者重新回到 2 登录进入 http://www.msuniversity.edu.cn/m_Directdownload/download.aspx, 点 “申请 Product Key 激活软件”, 出来页面中勾选同意许可协议, 最下面会出来一个 “Get Key” 的按钮, 点之获取我们需要的序列号

完成, 如果通过验证后, 第 7 步后会直接跳到 11, 就是说 8, 9, 10 都是只用做一次的

很多事情没做好是因为我不够用心

2008年10月12日

最近很乱, 想原因, 今天突然发现, 好像我已经很久没有特别专注的在做什么事情, 做事都是在得过且过, 然后自己又期望太高导致最后的结果不尽人意, 最后自己烦躁.
其实, 既然自己都没有做好, 那何必去要求太好的结果, 否则不是莫名其妙? 自己, 还是先专心一点的好.

这个学期, 想来也不会有太多的事情了, 好好弄好 MSTC 的事情. 那个陪伴了我几乎整个大学生活的 ACM/ICPC, 我已经全部放弃, 做的 OJ, 也不想再去过问, 一个烂摊子, 又是一件闹心的事情, 也是自己不够专注留下的祸. BBS, 想放, 不让放, 最后也还是要放掉的, 转个系统, 其实并不是太难的事情, 怎么到头来就还是这么麻烦. 学习, 好好按照原来那样来, 也不会弄的太好, 当然, 也应该不至于差到哪里去.

MSTC, 这个, 怎么说, 既然自己接过来了, 就还是好好的做下去, 在其位谋其政, 都没有别的事情了, 那就更需要认真了. 在这里, 还是有自己喜欢的人, 打交道都很舒服, 无论是技术, 抑或为人处世, 做的好一点, 也不算辜负前人希望, 也为后来人留一个好点的局面.

需要更多的专注, 把精力集中到一点, 然后爆发. 自己老在说别人不该同时做很多事情, 因为要想把事情做好, 那同时只能有一件事情排在自己的行动列表里, 事实上自己却在想很多事情也做很多事情最后在很多事情上放弃或失败. LOSER. I need to light my life.
